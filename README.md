# Waste Classification Using CNN

A CNN-based deep learning project that classifies waste images into:
- Cardboard
- Glass
- Metal
- Paper
- Plastic
- Trash

## Technologies
Python, TensorFlow, Keras, CNN, NumPy, Matplotlib, Scikit-learn, Flask, HTML, CSS.

## Setup

1. Install Python 3.10+.
2. Open this project folder in VS Code.
3. Install dependencies:

    pip install -r requirements.txt

4. Add images to the six folders inside `dataset/`.
5. Train the model:

    python train.py

6. Test one image:

    python predict.py test.jpg

7. Evaluate the model:

    python evaluate.py

8. Start the website:

    python app.py

9. Open in Chrome:

    http://127.0.0.1:5000

## Important

The ZIP contains the project code and empty dataset/model folders. You must add your own training images and run `python train.py` before using the prediction website.
